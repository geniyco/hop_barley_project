# Інтернет-магазин «Hop & Barley» на Django/DRF

## 📌 Опис проєкту
Це сучасний вебзастосунок інтернет-магазину для домашнього пивоваріння (продаж хмелю, солоду, дріжджів). Проєкт розроблено відповідно до вимог технічного завдання з використанням модульної архітектури, суворої типізації та інфраструктури Docker.

**Реалізований функціонал:**
- **Каталог товарів:** Фільтрація за категоріями/ціною, пагінація та пошук (CBV) [3.1].
- **Детальна сторінка товару:** Вивід характеристик та відгуків (1-5 зірок) [3.2].
- **Кошик:** Керування вмістом на основі Django Sessions з валідацією залишків на складі [3.3].
- **Чекаут:** Оформлення замовлень за допомогою безпечних атомарних транзакцій (`transaction.atomic`) [3.4].
- **Кабінет користувача:** Session-auth авторизація, реєстрація та історія замовлень [3.5].
- **REST API:** Повноцінні ендпоінти, захищені за допомогою JWT-токенів (access/refresh) [3.7].
- **Документація:** Автоматична інтерактивна документація OpenAPI/Swagger [3.8].

---

## 🛠️ Архітектура проєкту
Проєкт реалізовано за принципом розподілу відповідальності (Separation of Concerns):
- `config/` — Головні налаштування та маршрути проєкту.
- `users/` — Кастомна модель користувача, форми та API авторизації [3.5, 5].
- `products/` — Моделі товарів, категорій, відгуків, а також логіка каталогу [3.1, 4, 5].
- `orders/` — Серіалізатори, в'юсети замовлень та сервіс сесійного кошика [3.3, 3.4, 5].

## 🚀 Інструкція із запуску (Docker Compose)

Проєкт повністю контейнеризований і розгортається однією командою на будь-якій чистій системі:

1. **Клонуйте репозиторій та перейдіть у папку проєкту:**
   ```bash
   git clone <посилання_на_ваш_репозиторій>
   cd hop_barley_project
   ```

2. **Зберіть та запустіть Docker-контейнери:**
   ```bash
   docker-compose up --build
   ```

3. **Створіть суперкористувача (Адміністратора) для доступу в адмінку:**
   ```bash
   docker-compose run web python manage.py createsuperuser
   ```

4. **Відкрийте проєкт у браузері:**
   - Головна сторінка (Каталог): `http://localhost:8000/` [3.1]
   - Адмін-панель Django: `http://localhost:8000/admin/` [3.6]
   - Інтерактивна документація Swagger API: `http://localhost:8000/api/docs/` [3.8]

## 🔒 Приклади роботи з REST API (JWT Авторизація)

1. **Реєстрація нового користувача API:**
   - **POST** `/users/api/users/register/` [3.7]
   - Передати JSON: `{"username": "testuser", "password": "secure_password123", "email": "test@mail.com"}` [3.7]

2. **Отримання JWT-токенів (Логін):**
   - **POST** `/users/api/users/login/` [3.7]
   - Передати JSON: `{"username": "testuser", "password": "secure_password123"}` [3.7]
   - Відповідь: `{"refresh": "...", "access": "..."}` [3.7]

3. **Доступ до захищених ендпоінтів замовлень:**
   - Додати заголовок у ваш HTTP-клієнт: `Authorization: Bearer <ваш_access_токен>` [3.7]
   - **GET** `/api/orders/` — Перегляд лише своїх замовлень [3.7].

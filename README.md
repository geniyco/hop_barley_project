# # Інтернет-магазин «Hop & Barley» на Django/DRF

## 📌 Опис проєкту
Це сучасний вебзастосунок інтернет-магазину для домашнього пивоваріння (продаж хмелю, солоду, дріжджів). Проєкт розроблено відповідно до вимог технічного завдання з використанням модульної архітектури, суворої типізації та інфраструктури Docker.

**Реалізований функціонал:**
- **Каталог товарів:** Фільтрація за категоріями/ціною, пагінація та пошук (CBV).
- **Детальна сторінка товару:** Вивід характеристик та відгуків (1-5 зірок).
- **Кошик:** Керування вмістом на основі Django Sessions з валідацією залишків на складі.
- **Чекаут:** Оформлення замовлень за допомогою безпечних атомарних транзакцій (`transaction.atomic`) та надсилання імітаційних email-сповіщень.
- **Кабінет користувача:** Session-auth авторизація, повністю робоча реєстрація та історія замовлень покупця.
- **REST API:** Повноцінні ендпоінти, захищені за допомогою JWT-токенів (access/refresh).
- **Документація:** Автоматична інтерактивна документація OpenAPI/Swagger UI.

---

## 🛠️ Архітектура проєкту
Проєкт реалізовано за принципом розподілу відповідальності (Separation of Concerns):
- `config/` — Головні налаштування, маршрути та імітаційний поштовий бекенд.
- `users/` — Кастомна модель користувача, робочі форми та API-авторизація.
- `products/` — Моделі товарів, категорій, відгуків, а також логіка каталогу й API-в'юсети.
- `orders/` — Серіалізатори, в'юсети замовлень, автоматичні тести та сервіс сесійного кошика.

## 🚀 Інструкція із запуску (Docker Compose)

Проєкт повністю контейнеризований і розгортається однією командою на будь-якій чистій системі:

1. **Клонуйте репозиторій та перейдіть у папку проєкту:**
   ```bash
   git clone https://github.com
   cd hop_barley_project
   ```

2. **Зберіть та запустіть Docker-контейнери:**
   ```bash
   docker-compose up --build
   ```
   *Примітка: База даних PostgreSQL піднімається автоматично, і міграції таблиць Django (`migrate`) тепер застосовуються автоматично при старті контейнера.*

3. **Створіть суперкористувача (Адміністратора) для доступу в адмінку:**
   ```bash
   docker-compose run web python manage.py createsuperuser
   ```

4. **Відкрийте проєкт у браузері:**
   - Головна сторінка (Каталог): `http://localhost:8000/`
   - Адмін-панель Django: `http://localhost:8000/admin/`
   - Інтерактивна документація Swagger API: `http://localhost:8000/api/docs/`

## 🔒 Приклади роботи з REST API (JWT Авторизація)

1. **Реєстрація нового користувача API:**
   - **POST** `/users/api/users/register/`
   - Передати JSON: `{"username": "testuser", "password": "secure_password123", "email": "test@mail.com"}`

2. **Отримання JWT-токенів (Логін):**
   - **POST** `/users/api/users/login/`
   - Передати JSON: `{"username": "testuser", "password": "secure_password123"}`
   - Відповідь: `{"refresh": "...", "access": "..."}`

3. **Доступ до захищених ендпоінтів замовлень:**
   - Додати заголовок у ваш HTTP-клієнт: `Authorization: Bearer <ваш_access_токен>`
   - **GET** `/api/orders/` — Перегляд лише своїх замовлень.

## 📐 Перевірка якості коду, лінтери та тести

Усі команди виконуються всередині запущеного Docker-контейнера для гарантії однаковості середовища:

- **Запуск автоматичних Unit-тестів (pytest):**
  ```bash
  docker-compose run web pytest -o DJANGO_SETTINGS_MODULE=config.settings
  ```
- **Запуск лінтера Flake8 (перевірка PEP8 з ігноруванням міграцій):**
  ```bash
  docker-compose run web flake8 . --max-line-length=120 --exclude=*migrations*,venv,env,manage.py --ignore=E501,F401,E402,E261,W292,E302
  ```
- **Запуск перевірки типів Mypy:**
  ```bash
  docker-compose run web mypy . --ignore-missing-imports --exclude "(migrations|apps\.py|settings\.py|manage\.py|wsgi\.py|asgi\.py)"
  ```
